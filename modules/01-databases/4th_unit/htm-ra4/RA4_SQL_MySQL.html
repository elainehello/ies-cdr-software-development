Cómo usar esta guía

El objetivo es que ejecutes tú las sentencias, no que las leas. Todas las soluciones se han comprobado en MySQL 8.0 con el script ej_MYSQL.sql revisado. Cada ejercicio muestra el resultado que tienes que obtener.

1
Preparación. Crea tu usuario desde la terminal y carga ej_MYSQL.sql (pestaña 1). Comprueba que obtienes los mismos recuentos de filas que en la tabla de control.
2
Chuleta. Repasa la sintaxis de CREATE, ALTER, DROP, INSERT, UPDATE, DELETE, transacciones y usuarios (pestaña 2). Tenla abierta mientras practicas.
3
Práctica. Haz los ejercicios en orden: cada uno parte del estado que deja el anterior. Intenta escribir tu solución en Workbench, ejecútala y solo después pulsa «Ver solución». Compara tu resultado con el «resultado esperado» y marca ✔ cuando lo tengas.
4
Errores a propósito. Algunos pasos están marcados con ERROR esperado. Ejecútalos igualmente: ver el error 1093, 1451, 3819… y saber por qué salta es lo que más puntúa en el examen.
5
¿Lo has roto todo? Vuelve a ejecutar ej_MYSQL.sql completo: empieza con DROP DATABASE IF EXISTS Empleados y deja la base de datos como nueva.

1 · Preparación: usuario, contraseña y carga del script

Todo se puede hacer desde la terminal con el cliente mysql. Workbench es solo una interfaz gráfica sobre el mismo servidor.

1

Comprueba que el servidor está arrancado

-- Windows (CMD como administrador). El servicio suele llamarse MySQL80
net start MySQL80

-- Linux
sudo systemctl status mysql      -- y si está parado:  sudo systemctl start mysql

Si mysql «no se reconoce como comando» en Windows, añade C:\Program Files\MySQL\MySQL Server 8.0\bin al PATH o ejecuta desde esa carpeta.

2

Entra como administrador (root)

mysql -u root -p

-u es el usuario y -p hace que pida la contraseña (no la escribas pegada a -p delante de nadie: queda en el historial). El prompt cambia a mysql>.

3

Crea tu usuario y dale permisos

CREATE USER 'alumno'@'localhost' IDENTIFIED BY 'Alumno#2026';

GRANT ALL PRIVILEGES ON Empleados.* TO 'alumno'@'localhost';
GRANT ALL PRIVILEGES ON tiendas.*   TO 'alumno'@'localhost';
GRANT ALL PRIVILEGES ON videoclub.* TO 'alumno'@'localhost';

SHOW GRANTS FOR 'alumno'@'localhost';
EXIT;
ParteSignificado
'alumno'@'localhost'Un usuario MySQL es nombre + host. 'localhost' = solo puede conectarse desde tu equipo; '%' = desde cualquier host.
IDENTIFIED BYLa contraseña. Si sale el error 1819 (does not satisfy the current policy), el plugin validate_password exige una más fuerte: mayúscula, minúscula, número, símbolo y 8 caracteres o más.
Empleados.*Todos los objetos de esa base de datos. *.* = todo el servidor (no lo uses para un alumno).
ALL PRIVILEGESIncluye CREATE, DROP, ALTER, INSERT, UPDATE, DELETE, SELECT, CREATE VIEW y TRIGGER sobre esa BD. Permite incluso hacer DROP y CREATE de la propia base Empleados, que es lo que hace el script.

En MySQL 8, GRANT ya no crea usuarios: primero CREATE USER y después GRANT. No hace falta FLUSH PRIVILEGES con estas sentencias.

4

Conéctate con tu usuario y carga el script

Opción A — desde la terminal del sistema (sin entrar a mysql). Ve antes a la carpeta del fichero con cd:

mysql -u alumno -p < ej_MYSQL.sql

Opción B — desde dentro de mysql, con SOURCE y la ruta con barras normales /, también en Windows:

mysql -u alumno -p
SOURCE C:/Users/tu_usuario/Downloads/ej_MYSQL.sql;
5

Comprueba la carga (tabla de control)

SHOW DATABASES;
USE Empleados;
SHOW TABLES;
DESCRIBE EMPLOYEE;
SELECT 'EMPLOYEE' AS tabla, COUNT(*) FROM EMPLOYEE
UNION ALL SELECT 'CUSTOMER', COUNT(*) FROM CUSTOMER
UNION ALL SELECT 'ITEM', COUNT(*) FROM ITEM;
Debes obtener EMPLOYEE = 32, CUSTOMER = 33 e ITEM = 271. Si coincide, la base de datos está lista.
6

En MySQL Workbench

  1. Pantalla inicial → + junto a «MySQL Connections». Connection name: alumno · Hostname: 127.0.0.1 · Port: 3306 · Username: alumno → Store in Vault… (guarda la contraseña) → Test Connection.
  2. File → Open SQL Script… → ej_MYSQL.sql.
  3. Ejecutar: ⚡ (Ctrl+Shift+Enter) ejecuta todo el script o la selección; ⚡ con cursor (Ctrl+Enter) ejecuta solo la sentencia donde está el cursor. Para practicar, usa Ctrl+Enter de una en una.
  4. En el panel Schemas, pulsa ↻ (refrescar) para ver la base de datos nueva y haz doble clic en Empleados para dejarla como base por defecto (equivale a USE Empleados;).
  5. Mira siempre el panel Output: cada sentencia muestra ✔ o ✖, las filas afectadas y el mensaje de error.
Error 1175 «You are using safe update mode»: Workbench bloquea UPDATE y DELETE sin WHERE por clave. Ejecuta SET SQL_SAFE_UPDATES = 0; al principio de la sesión, o desmarca Edit → Preferences → SQL Editor → Safe Updates y reconecta.
Autocommit: Workbench confirma cada sentencia automáticamente. Para poder hacer ROLLBACK, empieza con START TRANSACTION; (o desactiva el botón de autocommit de la barra del editor).

5 · Del diagrama E/R al script SQL

Este es el tipo de ejercicio completo del examen: partir de un diagrama, escribir el modelo relacional y crear la base de datos con datos y operaciones. Sigue siempre este orden:

1
Entidades fuertes → una tabla cada una, con su identificador como PK. Si una entidad no tiene identificador (PUESTO), añade un código y explícalo.
2
Entidades débiles en identificación → PK = PK de la fuerte + clave parcial. FK con ON DELETE CASCADE.
3
Jerarquías → tabla del supertipo + una tabla por subtipo con PK = PK del supertipo, que también es FK (CASCADE). Exclusiva → un discriminante tipo NOT NULL CHECK IN (…). Solapada → un indicador 0/1 por subtipo. Total → el discriminante es NOT NULL (o, si es solapada, un CHECK que exija al menos un indicador a 1).
4
Relaciones 1:N → la PK del lado 1 viaja como FK al lado N, junto con los atributos de la relación. Mínimo 1 → NOT NULL. Mínimo 0 → NULL (y tiene sentido ON DELETE SET NULL).
5
Relaciones N:M → tabla nueva: PK = las dos claves concatenadas, cada una también FK, más los atributos de la relación. Los máximos y mínimos concretos (1,2) no caben en un CHECK: se indican y se resuelven con un trigger.
6
Script: CREATE en orden padres → hijas, INSERT en el mismo orden, pruebas de integridad, DML y transacciones. Para borrar, en orden inverso.

7 · Plan de examen RA4

Método para cada ejercicio (en este orden)

1
¿Qué tabla cambia? ¿Y en qué tabla está el dato con el que comparas? Si son distintas, usarás una subconsulta o un JOIN. Si es la misma, necesitas el truco de la tabla derivada (error 1093).
2
Primero un SELECT con el mismo WHERE que vas a usar. Si devuelve las filas correctas, cambia SELECT * por UPDATE … SET o DELETE.
3
Ejecuta y lee el Output: «N row(s) affected». 0 filas no siempre es un error (ejercicio 9.12), pero compruébalo.
4
Verifica con otro SELECT y, si el enunciado es ambiguo, escribe un comentario -- Interpreto que…. Los profesores valoran que justifiques.

Mis recomendaciones

  • Escribe en un fichero .sql, no directamente en la consola. Numera con -- Ejercicio 9.4, ejecuta con Ctrl+Enter de una en una y entrega el fichero: es tu evidencia.
  • Pon nombre a todas las restricciones (CONSTRAINT tiendas_pk …). Te ahorra buscar TIENDAS_ibfk_1 cuando tengas que hacer DROP FOREIGN KEY.
  • Crea en orden padres → hijas e inserta en ese mismo orden. Para borrar, al revés: hijas → padres.
  • MODIFY redefine la columna entera: repite NOT NULL, DEFAULT y COMMENT si los tenía, o los perderás sin aviso.
  • Antes de un DELETE o UPDATE masivo, abre una transacción. Si te equivocas, ROLLBACK; y vuelves a empezar. Recuerda que CREATE, ALTER y DROP no se deshacen.
  • Practica los ejercicios de dos maneras: primero siguiendo el orden de la guía, y después volviendo a cargar el script y haciéndolos sin mirar. Si en la segunda ronda los sacas solos, estás listo.
  • Prepara un «ejercicio sorpresa»: inventa un enunciado con otra tabla del esquema (SALES_ORDER, ITEM…) y resuélvelo con los mismos patrones. Por ejemplo: «subir un 5 % el precio de los productos que nunca se han vendido».

Comprueba tu dominio

Reto 1. Crea una tabla BONUS con CREATE TABLE … AS SELECT que contenga EMPLOYEE_ID, LAST_NAME y el 15 % del salario de los MANAGER.
Solución
CREATE TABLE BONUS AS
SELECT EMPLOYEE_ID, LAST_NAME, SALARY * 0.15 AS BONO
FROM EMPLOYEE
WHERE JOB_ID = (SELECT JOB_ID FROM JOB WHERE FUNCTIONS = 'MANAGER');

CREATE TABLE … AS SELECT copia columnas y filas, pero no copia la PK, las FK ni los CHECK.

Reto 2. Añade a BONUS una PK, una columna FECHA (NOT NULL, con la fecha de hoy por defecto) y un CHECK para que BONO > 0.
Solución
ALTER TABLE BONUS ADD CONSTRAINT bonus_pk PRIMARY KEY (EMPLOYEE_ID);
ALTER TABLE BONUS ADD FECHA DATE NOT NULL DEFAULT (CURDATE());
ALTER TABLE BONUS ADD CONSTRAINT bonus_bono_ck CHECK (BONO > 0);

En MySQL 8, un DEFAULT con una función va entre paréntesis: DEFAULT (CURDATE()).

Reto 3. Dentro de una transacción, borra todas las filas de BONUS, compruébalo con COUNT(*), deshazlo y vuelve a contar.
Solución
START TRANSACTION;
DELETE FROM BONUS;
SELECT COUNT(*) FROM BONUS;   -- 0
ROLLBACK;
SELECT COUNT(*) FROM BONUS;   -- vuelven las filas
DROP TABLE BONUS;             -- DDL: esto ya no tiene vuelta atrás
